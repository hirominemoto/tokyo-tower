# 東京タワー、見上げる場所（60秒）

ゴゴ（Claude Opus 5.5）が作り、Fable（Claude Fable 5.2）が人物・音楽などに手を入れた、東京タワーの60秒映像のコード一式です。

## 中身

| ファイル | 何か |
| --- | --- |
| `index.html` | できあがったページ。ダブルクリックでブラウザが開き、そのまま60秒流れます（three.js も中に入っているので、これ1つで動きます） |
| `src/main.js` | 映像の本体。塔・街・人・カメラの動き・字幕はすべてここ |
| `src/template.html` | 画面の枠と字幕・タイトルの見た目（フォントはMeiryo） |
| `build.mjs` | `src/` から `index.html` を作るスクリプト |
| `render.mjs` | `index.html` を1コマずつ撮って MP4 に書き出すスクリプト（ゴゴの元の版） |
| `seq.mjs` | 同じく1コマずつ撮るスクリプト（Fableの作業環境用。`frames/` に連番画像を出す） |
| `music/compose.py` | 音楽を作るスクリプト（Python + numpy/scipy）。実行すると `music/score.wav` ができる |
| `music/score.mp3` | ページに埋め込む音楽。`build.mjs` が `index.html` の中に入れる |
| `package.json` | 使っている部品（three.js 0.170、esbuild） |

## main.js の中の目印

- `TOKYO TOWER` … 塔（333m、赤と白の11段）
- `CITY` … 街のビル・街灯・車の光
- `大門通り` / `増上寺` / `芝公園` / `三田の路地` … 各場面の街並み（コンビニもここ）
- `PEOPLE` … 人の形と歩き方
- `CAST & SCENES` … 登場する人たち
- `const CAPS` … 字幕の文と出る秒数
- `function camAt` … 秒ごとのカメラの位置
- `POV close-up` … 缶ビールの手元のアップ

## 作り直すとき

1. このフォルダでターミナルを開く
2. `npm install` を実行する
3. `src/main.js` などを直す
4. `node build.mjs` を実行すると `index.html` が新しくなる

`render.mjs` は、Chrome と Playwright と ffmpeg の場所をゴゴの作業環境に合わせて書いてあります。自分のパソコンで MP4 を書き出したいときは、ゴゴに言ってください。

## 2026-11-15 Fable が手を入れたところ

構成・カメラ・字幕はゴゴの版のまま。変えたのは次の4点。

- **人物**（`PEOPLE`）… 手足を「先細りの筒＋関節で同じ太さ」に作り直して、ひじ・ひざのすき間をなくした。胴・頭・髪・手・マフラーも分割を細かく、丸く。
- **ちかちか** … 地面が2枚の巨大な三角形だったせいで、奥行きの計算が1コマだけ狂い、路地の地面が黒くせり上がるコマが混ざっていた。地面を細かく分割し、奥行きバッファを対数式に（`logarithmicDepthBuffer`）、カメラの near を場面ごとに調整。航空障害灯の点滅もなめらかに。
- **切り替え** … 手元のアップへ（39.5秒）と引きの絵へ（44秒）がいきなり切り替わっていたので、短い「まばたき」の暗転を入れた。カメラの後ろから来る通行人が目の前に突然現れるのも直した。
- **人物の作り込み** … 指のある手（ベンチの人と路地の子どもが塔を指さす）、手をつなぐ親子、足元の影、体重移動のある歩き方、鼻と耳。
- **冒頭** … 字幕を「立ち止まって、見上げる人がいる。」に。彼女が止まったあと、カメラが肩の後ろへ回り込んで、見上げる後ろ姿を画面に残す。
- **コンビニ** … 店から出てくる → カメラが後ろ姿に寄る → 缶を持った手のアップ。字幕「缶ビールひとつ。」「ただいま…」は手のアップに。そのあとの引きの絵には彼女を出さない。「ただいま…」の余韻のために、手のアップを45秒まで延ばした（引きの絵は45秒から）。
- **芝公園** … 犬の散歩の人・犬・ジョギングの人・通行人が、進む向きと逆を向いて歩いていたのを直した。
- **音楽** … `music/compose.py` で作った60秒の曲を追加。ページは最初に再生ボタンを押す形に（ブラウザは、押す前に音を出せないため）。右下の ♪ で音のオン／オフ。

音楽を作り直すとき： `python3 music/compose.py` → `ffmpeg -i music/score.wav -b:a 112k music/score.mp3` → `node build.mjs`

## 公開（Vercel）
